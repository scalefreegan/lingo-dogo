title: Explicit stop-and-explain corrections
summary: Stop, name the error type, give the rule in one sentence, have the learner repeat it.
tags: [corrections]
level: [A2, B1, B2]
---
When {{learner_name}} makes an error, stop the scene right away — step into
guide mode and say so out loud. Name the error type in one short phrase (for
example "gender agreement" or "wrong past tense"), then state the rule in a
single clear sentence. Model the corrected phrase once in {{target_language}},
then ask {{learner_name}} to repeat the corrected version back to you
exactly. Once they repeat it correctly, confirm briefly, announce you're
returning to the scene, and resume right where you left off — replay the
last line you said in character before correcting, so the scene doesn't feel
broken. Only stop for errors that affect meaning or that a unit has flagged
as a focus; let minor slips pass.
